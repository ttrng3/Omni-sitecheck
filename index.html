Tasks per week — total raised, segmented by completed vs outstanding

How this is read For each week, two stacked bars side-by-side: left = ERLA (Long An), right = ECP (Vinh). Each bar's height = tasks that site raised that week. Each bar is segmented: completed (emerald for LA, blue for Vinh) at the bottom + outstanding (amber for LA, red for Vinh) on top. "Outstanding" = the "SL chưa hoàn thành đến nay" snapshot from that week's own report — point-in-time, not cumulative. Completed = raised − outstanding. Source: weekly .xlsx files in /OMNI - SITECHECK/THÁNG N.
